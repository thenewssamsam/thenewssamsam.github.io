📂 專案結構

beyondthenewssam/
├── _layouts/            ← 網站模板（含 AdSense）
├── _posts/              ← 文章會自動放在這裡
├── assets/              ← CSS 和 JavaScript
├── .github/workflows/   ← GitHub Actions 自動化
├── main_github.py       ← 發布程式
├── publisher_github.py  ← 發布者（GitHub）
└── 文檔文件

🚀 立即開始

1. 建立 GitHub Repository：thenewssamsam.github.io
2. Push 代碼到 GitHub
3. 啟用 GitHub Pages（Settings → Pages）
4. 添加 Gemini API Key 到 GitHub Secrets
5. 手動測試一次（Actions → Run workflow）
6. 完成！每天自動發布
